# Memory Review Template

Use this against the memory or persistent context an AI assistant is carrying forward.

| POI | Function | Description | Notes | Class | Keep? | Why? |
|---|---|---|---|---|---|---|
|  |  |  |  | Governance / Operating context / Preference / Ephemera | Yes / No / Temporary |  |

## Review questions

- Does this help the assistant make materially better decisions?
- Is it still true?
- Is it appropriate to persist?
- Would publication expose personal, confidential, security, or customer information?
- Is this governance, operating context, preference, or ephemera?
- Does it need an explicit human gate?
- Can the same value be achieved with less retained information?
- Should it expire?
